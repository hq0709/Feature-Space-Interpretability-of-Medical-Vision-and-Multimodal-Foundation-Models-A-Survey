# Feature-space interpretability of medical vision and multimodal foundation models: a survey (v7.29)

Overleaf-linked copy of the article. Main document: `main.tex` (elsarticle, pdflatex + bibtex).
Supplementary tables: `supplement/supplement_tables.tex`.

by `tools/export_overleaf.sh` after `tools/build.sh`; edit those sources there and re-export rather
than editing the generated files here. Author artwork goes in `figures/` under the existing file names.
